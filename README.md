# KoShorts — сайт Telegram-бота (`koshorts.vercel.app`)

Двуязычный (RU / EN) лендинг для Telegram-бота **[@remtex_shorts_ai_bot](https://t.me/remtex_shorts_ai_bot)**, который автоматически нарезает длинные видео в вертикальные Shorts `9:16` с пословными субтитрами.

- **Рабочий сайт:** <https://koshorts.vercel.app/>
- **Английская версия:** <https://koshorts.vercel.app/en/>
- **Политика конфиденциальности:** <https://koshorts.vercel.app/privacy/>
- **Условия использования и подписки:** <https://koshorts.vercel.app/terms/>

---

## Из каких файлов состоит сайт

| Файл / папка | За что отвечает |
| --- | --- |
| `index.html` | Главная страница сайта (на русском языке по умолчанию) |
| `en/index.html` | Готовая английская версия главной страницы (для Google и ссылок в соцсетях) |
| `privacy/index.html` | Страница «Политика конфиденциальности» (RU / EN) |
| `terms/index.html` | Страница «Условия использования и подписки» (RU / EN) |
| `assets/i18n.js` | **Все тексты главной страницы** на русском (`ru`) и английском (`en`) |
| `assets/legal-i18n.js` | Все тексты юридических страниц (`/privacy/` и `/terms/`) на RU и EN |
| `assets/styles.css` | Оформление, цвета, шрифты и адаптация под телефоны / компьютеры |
| `assets/app.js` | Переключение языка `RU / EN`, открытие видео YouTube и окна просмотра Shorts |
| `og.png`, `og-en.png` | Картинки-обложки `1200×630` при отправке ссылки на сайт в Telegram и соцсети |
| `vercel.json` | Настройки безопасности и кеширования для хостинга Vercel |
| `tests/` | Автоматические проверки сайта (тексты, языки, видеоплеер, доступность) |

## Шпаргалка: где и что менять на сайте

> **Главное правило:** чтобы русская и английская версии всегда совпадали, меняйте текст **и в `index.html`**, **и в `assets/i18n.js`** (в блоках `ru` и `en`), а если у вас установлен Node.js — выполните команду `npm run sync`, и файл `en/index.html` обновится сам автоматически.

### 1. Изменить остаток мест со скидкой Early Adopter (сейчас `12 из 50`)
Откройте:
1. `assets/i18n.js` — обновите ключи `promo_badge`, `ea_spots` и `final_note` в разделе `ru` (например, `Занято 42 из 50 · Осталось 8 мест`) и в разделе `en` (`42 of 50 claimed · 8 spots left`).
2. `index.html` — обновите те же строки (`data-i18n="promo_badge"`, `data-i18n="ea_spots"`, `data-i18n="final_note"`), а ширину полоски заполнения при желании подправьте в `assets/styles.css` (`.ea-bar-fill { width: 76%; }`).
3. Выполните `npm run sync` (или обновите те же числа в `en/index.html`).

### 2. Изменить цены, курс гривны или цену в Telegram Stars
- Цены в долларах (`$0`, `$9`, `$29`, `$499`) находятся прямо в `index.html` (и `en/index.html`) в разделе `<!-- PRICING (#pricing) -->`.
- Пересчёт в гривны, Stars и выгода за 1 Short находятся в `assets/i18n.js` (ключи `cr_eq`, `cr_ea`, `cr_unit`, `st_eq`, `st_ea`, `st_unit`, `tk_uah`) и дублируются в `index.html`.

### 3. Обновить цифры просмотров Shorts
Когда просмотры ваших роликов снова вырастут:
1. Откройте `index.html` и найдите `230K`, `5.6K`, `11.6K`, `274K` (в блоках `STATS` и `DEMO`).
2. Для подписи под исходным видео также обновите ключ `demo_cap_prefix` в `assets/i18n.js`.
3. Выполните `npm run sync` (или обновите те же числа в `en/index.html`).

### 4. Ссылки-метки для Telegram-бота
Кнопки на сайте ведут в бота с разными метками, чтобы бот понимал, какую кнопку нажал человек:
- Бесплатный старт: `https://t.me/remtex_shorts_ai_bot?start=free`
- Тариф Creator: `https://t.me/remtex_shorts_ai_bot?start=creator`
- Тариф Studio: `https://t.me/remtex_shorts_ai_bot?start=studio`
- Ведение под ключ: `https://t.me/remtex_shorts_ai_bot?start=turnkey`

## Как проверить сайт на своём компьютере (необязательно)

Сайт работает из обычных статических файлов — Vercel публикует их напрямую без сложной сборки. Если захотите запускать автопроверки локально:

```bash
# 1. Установить инструменты проверки (один раз)
npm install

# 2. Автоматически обновить английскую страницу en/index.html из словаря
npm run sync

# 3. Запустить быстрые автотесты (проверят языки, ссылки, плеер и отсутствие ошибок)
npm test

# 4. Пересоздать картинки превью og.png и og-en.png (если меняли скрипт генерации)
npm run build:assets
```

## Как обновляется живой сайт `koshorts.vercel.app`

Ваш аккаунт **Vercel** подключён к главной ветке `main` этого репозитория на GitHub:
1. Любое изменение, принятое (Merge) или сохранённое в ветку `main`, автоматически подхватывается Vercel.
2. Через 10–20 секунд обновлённая версия появляется на <https://koshorts.vercel.app/>.
